Пакет инструментов Gibbed Illusion Tools для редактирования файлов Mafia II.

Автор: Rick

**Инструкция:  
**Для экспорта из DLC, необходимо перетащить файл на Gibbed.Illusion.DecryptSDS.exe, после этого появится файл "имя\_файла\_decrypted.sds"  
Теперь мы можем работать с этим файлом. Например, файл легко открывается и экспортируется SDSTool или Gibbed.Illusion.ExploreSDS.exe
