**Особенности:**

-   Две версии машины,
-   Своя коллизия,
-   Рабочий руль,
-   Рабочие дворники,
-   Реальное отражение в зеркалах.

Возможно Add-on установка (без замены). Инструкция в архиве. Для Add-on установки машины требуется Update 5.

**Автор конвертации:** agens

**Заменяет:** Parry bus

**Установка:**

1.  Cкопировать файлы из архива из папки Replace — parry\_bus.sds, parry\_bus\_z.sds: в папку с игрой по пути: \\Mafia II\\pc\\sds\\cars\\
2.  Файлы из архива (из папки edit) mercury-coupe-1949.mtl  утилиту MafiaIIMaterialsMerger.exe скопировать в папку с игрой по пути /edit/materials/
3.  Запустить утилиту MafiaIIMaterialsMerger.exe из папки MafiaII/edit/materials/
